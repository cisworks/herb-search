# 생약검색 홈페이지

대한민국약전·생약(한약)규격집(hwpx)과 관능검사해설서(PDF)를 파싱해서 생약 품목을
검색하고 열람할 수 있게 해주는 Flask 웹앱입니다.

## 실행 방법

```bash
pip install -r requirements.txt
python app.py
```

브라우저에서 `http://127.0.0.1:5000` 접속.

앱 실행 시 폴더 안의 모든 `*.hwpx`, `*.pdf` 파일을 자동으로 찾아 파싱해서
메모리 데이터베이스로 사용합니다. 별도의 DB 없이, 원본 문서 파일을 교체하고
앱을 재시작하면 데이터가 갱신됩니다.

## 프로젝트 구조

```
생약검색 홈페이지/
├── app.py                     Flask 앱 진입점, 라우팅·검색 API
├── parse_hwpx.py              hwpx 공정서 파서 (핵심 로직)
├── parse_sensory_pdf.py       관능검사해설서 PDF 파서
├── requirements.txt           Flask, pymupdf
├── templates/
│   └── index.html             단일 페이지 UI (검색 + 상세 뷰)
├── static/
│   └── seoul_logo.png         서울시 휘장 로고
├── *.hwpx (2개)                원본 데이터: 약전 각조 제2부, 생규집 각조 제1부
└── 관능검사해설서(2022).pdf     원본 데이터
```

## 컴포넌트별 역할

### [app.py](app.py)
- 시작 시 폴더 내 모든 `*.hwpx` / `*.pdf`를 자동으로 찾아 파싱해 메모리에 로드
  (`ENTRIES`, `SENSORY_ENTRIES`)
- 라우트
  - `/` — 메인 페이지
  - `/api/list` — 전체 공정서 품목 목록
  - `/api/search` — 검색 (공정서 + 관능검사 통합)
  - `/api/item/<id>` — 품목 상세
  - `/api/sensory_pdf` — 해당 품목의 관능검사해설서 페이지 구간만 잘라 PDF로 스트리밍
- 파일명에 "약전"이 있으면 `KP`, "생규"/"생약규격"이 있으면 `KHP` 배지 태그 부여
- hwpx(공정서)와 PDF(관능검사)의 id 공간을 하나로 이어붙여 통합 조회

### [parse_hwpx.py](parse_hwpx.py)
가장 복잡한 모듈로, hwpx(zip+XML) 문서 구조를 다음과 같이 파싱합니다.
- "항목명" 문자 스타일을 스타일 카탈로그(`header.xml`)에서 동적으로 찾음
  (문서마다 스타일 ID가 다르기 때문)
- 품명 줄(국문명/한자/영문명/라틴명)은 스타일이 아닌 텍스트 패턴(짧고 문장이
  아닌 형태)으로 휴리스틱 판별
- 성상/확인시험/순도시험/건조감량/정량법 등 계층적 섹션과 하위 항목 파싱,
  수식(아래첨자) 변환 포함
- 순도시험 등에서 다른 품목을 참조하는 문구(예: "「두충」의 순도시험에
  따른다")를 실제 품목 id로 연결하는 후처리 포함

### [parse_sensory_pdf.py](parse_sensory_pdf.py)
- PyMuPDF의 위치기반 정렬 추출(`sort=True`) 사용 — 한자가 원문 위에 겹쳐
  배치된 PDF라 순서 보정이 필요
- 페이지 첫 줄이 `"KP/KHP 이름(한자)"` 패턴이면 새 품목 시작으로 판단,
  다음 품목이 시작되기 전까지의 텍스트를 묶어서 하나의 품목으로 구성

### [templates/index.html](templates/index.html)
단일 페이지: 검색창 + 결과 목록 + 상세 패널(공정서 항목 또는 관능검사
PDF 뷰어)로 구성.

## 참고 사항

- 데이터베이스가 없으며, 실행할 때마다 원본 문서를 메모리로 파싱합니다.
- 원본 데이터 파일(hwpx 2개, PDF 1개)이 저장소 루트에 직접 포함되어 있으며,
  PDF는 약 200MB로 용량이 큽니다.
- 모듈 수가 적어 `src/` 디렉토리 분리 없이 평면 구조로 되어 있습니다. 향후
  파서가 늘어나면 `parsers/` 하위로 정리하는 것을 고려할 수 있습니다.
